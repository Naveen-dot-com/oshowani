Privacy Policy

Short version: Oshowani does not collect, store, or share any personal data on our servers. Your conversations stay on your device. The only third-party services used are Google Gemini API (for AI responses) and Cloudflare (for secure API routing). We do not track you.

1. Who We Are

Oshowani is a spiritual AI chat application developed by Naveen Dubey, an independent developer based in Varanasi, India. Available as a PWA and on Google Play as a Trusted Web Activity (TWA).

App: naveen-dot-com.github.io/oshowani/
Contact: n.k.dubey1997@gmail.com

2. What Data We Collect

We collect no personal data on any server we control. No account or sign-in required.

We do not collect, transmit, or store:

  • Your name, email address, or phone number
  • Your location or IP address
  • Device identifiers, Android ID, or advertising IDs
  • Payment information of any kind
  • Photos, videos, or any media from your device

3. Data Shared with Third Parties

Data Type Sent To Purpose Stored by Us?
Your chat message text Cloudflare Worker → Google Gemini API Generate AI response No
Conversation history (session) Cloudflare Worker → Google Gemini API Contextual responses No — device only
Notification prompt request Cloudflare Worker → Google Gemini API Generate daily thought No

All communication uses encrypted HTTPS (TLS 1.2 or higher).

4. Cloudflare Worker Proxy

All AI requests are routed through a Cloudflare Worker — a serverless proxy that hides the Gemini API key from client code.

  • The Worker forwards your message to Gemini and returns the response
  • It does not log, store, or retain any request or response content
  • The Gemini API key is stored as an encrypted Cloudflare secret
  • Cloudflare may process network-level metadata (e.g. IP addresses) as part of standard routing — we have no access to this

5. Conversation Data & Local Storage

Your chat history is saved only on your device using browser localStorage. The following is stored locally only:

  • Chat history and past conversation sessions
  • Language preference (e.g. English, Hindi)
  • Theme preference (light or dark mode)
  • Whether you dismissed the notification prompt

Delete all data anytime: Android Settings → Apps → Oshowani → Storage → Clear Data.

6. Push Notifications

Optional daily push notifications with a short spiritual thought are generated via the Gemini API.

  • Permission is always optional. You can revoke it anytime in Settings → Notifications → Oshowani
  • No device push token or user subscription ID is collected or stored by us
  • Periodic Background Sync may trigger daily notification generation on supported devices — making one standard Gemini API call with no additional personal data
  • If Gemini is unavailable, a pre-written offline fallback message is shown — no network request is made

7. Permissions Used

No access to Contacts, Camera, Microphone, Location, File Storage, SMS, or Calendar is requested.

8. Third-Party Services

  • Google Gemini API — generates AI responses. Governed by the Google Privacy Policy and Gemini API Terms.
  • Cloudflare Workers — secure serverless proxy. No user content stored by Cloudflare on our behalf. See Cloudflare Privacy Policy.

9. Children's Privacy

Oshowani is not directed at children under 13. We do not knowingly collect information from children. Contact us at n.k.dubey1997@gmail.com if you have a concern.

10. Data Security

All communication uses HTTPS with TLS 1.2 or higher. The Gemini API key is stored as an encrypted Cloudflare secret and never exposed to the client. We operate no database, so there is no risk of a server-side breach affecting your conversations.

11. Data Retention & Deletion

We retain no user data on our servers. To delete all Oshowani data: Android Settings → Apps → Oshowani → Storage → Clear Data. This is immediate and permanent.

12. Your Rights

Since we store no personal data server-side, there is nothing held by us to access, correct, or delete. You may at any time revoke notification permission, clear local app data, or contact us with any privacy request.

EEA residents may have rights under GDPR. California residents may have rights under CCPA. Contact us at n.k.dubey1997@gmail.com to exercise any such rights.

13. International Data Transfers

Message text is transmitted to Google Gemini API and Cloudflare, which may process data in the United States. These transfers are made under appropriate safeguards as described in their respective privacy policies.

Any changes will be reflected on this page with an updated "Last updated" date. We encourage you to review this policy periodically.
